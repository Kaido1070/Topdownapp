# Topdown — تطبيق أندرويد

تطبيق أندرويد أصلي (Kotlin) يعرض موقع **Topdown** داخل WebView، بواجهة زجاجية
ومزايا تحميل كاملة. التطبيق لا يغيّر شيئًا في الموقع نفسه.

## تغيير رابط الموقع
في `gradle.properties`:
```
TOPDOWN_URL=https://your-topdown-site.com/
```
أو وقت البناء: `./gradlew assembleRelease -PTOPDOWN_URL=https://...`

## المزايا
- **واجهة زجاجية**: شريط علوي وشريط سفلي عائم شفاف مع لمعة وظلال، وتمويه حقيقي للخلفية على أندرويد 12+، ووضع فاتح/داكن.
- **إعادة التحميل**: السحب للأسفل، وزر إعادة/إيقاف مع شريط تقدّم، وإعادة تلقائية عند رجوع الإنترنت.
- **التحميل**: يلتقط تحميلات الموقع (روابط عادية و`blob:` و`data:`)، ويحفظها في `Download/Topdown`، مع الكوكيز ووكيل المستخدم (User-Agent) والمُحيل (Referer) لكي تعمل الروابط المحمية.
- **اختيار الجودة**: يكتشف الفيديو والصوت وروابط الملفات في الصفحة ويعرض زر «تحميل الوسائط» → قائمة بالجودات (4K/1080p/720p…)، مع جودة مفضّلة وخيار «استخدم هذه الجودة دائمًا».
- **شاشة التحميلات**: تقدّم مباشر، فتح، مشاركة، حذف/إلغاء، وإعادة محاولة للتحميل الفاشل، وشارة بعدد التحميلات الجارية.
- **ملء الشاشة للفيديو** مع التدوير التلقائي.
- **رفع الملفات** (`<input type=file>`).
- **ضغط مطوّل** على الروابط والصور: تحميل، نسخ، مشاركة، فتح في المتصفح.
- **الروابط الخارجية** وروابط `intent:` و`tel:` و`mailto:` و`whatsapp:` تفتح في تطبيقاتها.
- **الإعدادات**: الجودة، التحميل عبر Wi‑Fi فقط، وضع سطح المكتب، تعتيم الموقع، حجم النص، إبقاء الشاشة مضاءة، إخفاء الشريط تلقائيًا، مسح الذاكرة المؤقتة والكوكيز.
- شاشة بداية (Splash)، وزر رجوع ذكي (الضغط مرتين للخروج)، وحفظ الجلسة، واستقبال الروابط عبر «مشاركة».

## البناء
```
./gradlew assembleRelease
```
الناتج: `app/build/outputs/apk/release/app-release.apk`.
كل دفعة (push) إلى GitHub تبني ملف APK تلقائيًا (Actions ← Build APK ← Artifacts).

> نسخة الإصدار موقّعة حاليًا بمفتاح التصحيح (debug). للنشر في Google Play أضف مفتاح توقيع خاصًا بك.
