# Topdown — تطبيق الآيفون (وأندرويد)

تطبيق يعرض موقع **https://topdownn.pages.dev** من داخله، مع التحميل والتصفح بدون إنترنت.

## iOS (`ios/`)
SwiftUI + WKWebView، يحتاج iOS 26 أو أحدث.

- **التحميل:** يلتقط الفيديو الذي تشغّله من `/api/resolve` والفصل الذي تقرؤه من `/api/story/chapter`، ويظهر زر «تحميل».
  - الفيديو بصيغة HLS يُحمّل عبر `AVAssetDownloadURLSession` مع اختيار الجودة من الجودات المتاحة في البث.
  - ملفات MP4 تُحمّل عبر جلسة خلفية مع كوكيز الدخول.
- **القصص:** تحميل فصل واحد، أو الفصول العشرة التالية، أو كل الفصول. الصور تُجلب من رابطها الأصلي، ثم من `/api/manga-image` إذا فشل.
- **بدون إنترنت:** مكتبة للفيديو والقصص، ومشغل النظام (صورة داخل صورة، AirPlay، ومتابعة من آخر نقطة)، وقارئ يحفظ آخر صفحة.
  - إذا فتحت التطبيق بدون اتصال يفتح على المكتبة مباشرة.
- **الواجهة:**
  - تصميم Liquid Glass.
  - شريط تبويبات يصغر أثناء التمرير.
  - شريط تحكم فوق التبويبات: رجوع، تقدّم، إعادة تحميل، الرئيسية، تحميل.
  - السحب لإعادة تحميل الصفحة.
- **الخصوصية:** قفل بـ Face ID، وإخفاء المحتوى في مبدّل التطبيقات.
- **مزايا أخرى:** إشعارات عند اكتمال التحميل، واختصارات Siri، وظهور المحمّلات في تطبيق «الملفات».

### البناء
كل دفعة (push) على `ios/` تشغّل `.github/workflows/ios.yml` على جهاز macOS، فيُنشئ المشروع بأداة XcodeGen ويبني ملف IPA غير موقّع.
تجد الملف في Releases ← `ios-latest` ← `Topdown-unsigned.ipa`.

محليًا على جهاز Mac:
```
brew install xcodegen
cd ios && xcodegen generate && open Topdown.xcodeproj
```

## Android (`app/`)
Kotlin + WebView. البناء: `./gradlew assembleRelease`.
